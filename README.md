
# Student Manager (Python)

A simple console app to manage a list of students.

## Features
- Add a student
- View all students
- Delete a student by number
- Names are saved in `students.txt`, so they stay after closing the program

## Built with
Python (lists, loops, functions, file handling)

## How to run
1. Install Python
2. Run `python main.py`
3. Choose an option from the menu
